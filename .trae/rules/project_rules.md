## 计算约定（按该版教材的通用写法）
- 渠道输水损失经验公式：
  - σ = A / (100 · Q净^m)   （σ 为每公里损失系数，Q净单位 m³/s）
  - Q损 = σ · L · Q净
  - Q毛 = Q净 + Q损 = Q净(1 + σL)
  - η渠道 = Q净 / Q毛 = 1 / (1 + σL)
- 渠系水利用系数逐级相乘：η系 = η干·η支·η斗·η农
- 灌溉水利用系数：η = η系 · η田
- 灌水率 q设 按净灌水率（田间净流量）计：Q净 = q设·A；
  求渠首毛流量时计入田间水利用系数 η田 与各级渠道效率
- 土壤透水性参数：重壤土 A=1.3, m=0.35；中壤土 A=1.9, m=0.40
  （其余土壤类型以教材透水性参数表为准，未确认前不要臆造）
- 续灌渠道设计流量取毛流量；轮灌渠道按轮灌组数放大
- 加大流量 = 设计流量 × 加大系数（一般 1.2~1.3）
- 干渠由下游向上游逐段推算；支渠损失按各支渠实际长度分别计算；
  典型支渠用于求斗渠、农渠与田间各级效率

### 覆盖内容
- 农田水利学：作物需水与灌溉定额、灌水率、续灌/轮灌与加大流量、
  渠道输水损失、支渠/干渠设计流量、渠系水利用系数、梯形断面与曼宁公式、
  正常水深、水力最优断面。
- 土力学：三相指标、达西定律与等效渗透系数、临界梯度与有效应力、
  压缩系数/压缩模量/沉降、分层总和法、一维固结、莫尔–库仑强度、
  主应力、朗肯土压力、挡墙稳定、太沙基承载力、边坡稳定
  （无限边坡/瑞典条分/毕肖普）。
- 工程水文学：经验频率、矩法参数、P-III 频率曲线与设计值、
  同频率/同倍比放大、推理公式、暴雨强度、Horton 下渗、
  马斯京根与线性水库演算、线性相关、径流深/径流总量。

### 单位约定
- 土力学：kPa / MPa / kN·m⁻³；水文学：mm、km²、m³/s、万 m³；
  农田水利学：m³/s、km、万亩。
- P-III 的 p 为**超过频率**（设计频率），内部按累积概率 1-p 计算。
